# Аудит · TG Matrix Kit

Дата: 2026-10-08. Репозиторий: [kipingame-cell/tg-matrix-kit](https://github.com/kipingame-cell/tg-matrix-kit). Видимость: **public**. Исходный коммит: `7e364ae342a8d21d621cd98497a3e0d7c1b3dce0`.

## Назначение и устройство

Локальный Node.js-терминал для выгрузки Telegram-чатов, графа связей, анализа активности и опциональных ИИ-досье.

Тип: Node.js · Telegram. Версия из фактических источников: **1.0.0**.

Файлов исходного дерева: **20**. Прочитано доступных текстовых файлов для проверки: **19**. Кэши, бинарные сессии и крупные двоичные файлы не исполнялись. Файлы APK проверяются в предназначенном для них CI.

Основные части: `server.js · src/ · public/tg/ · public/graph/ · public/heatmap/ · tg_backup/`.

## Проверки и ограничения

Исходники JavaScript проверены на синтаксис. Интеграционные проверки с Telegram, PostgreSQL и внешними ИИ не выполнялись; CI отсутствовал.


## Выявленные проблемы

- P0: сервер без полноценной защиты API нельзя выставлять в открытый интернет.
- P1: SESSION_SECRET должен оставаться постоянным; его смена лишает доступа к ранее зашифрованным сессиям.
- P1: README обещает отсутствие внешней передачи, хотя ИИ и бот могут передавать выбранные данные.
- P2: нужны lock-файл и тесты жизненного цикла фоновой выгрузки.

## Предложения

1. Ввести реальную локальную авторизацию и привязку sid/экспортов к пользователю.
2. Разделить обычный экспорт и явно включаемые ИИ/бот-интеграции.
3. Ограничить срок хранения архивов и добавить безопасную очистку.
