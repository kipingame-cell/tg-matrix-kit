# TG MATRIX KIT

Локальный терминал для выгрузки и анализа Telegram-чатов. Работает на твоём устройстве (ПК, Android через Termux или Docker), ничего не уходит на чужие серверы.

## Возможности

- **Выгрузка чатов** — сообщения в TXT / HTML / JSON, нарезка на части, превью медиа, ZIP-архив.
- **Фильтры** — по ключевым словам, участнику, датам, веткам (топикам) форумов, типу контента.
- **Фоновая выгрузка** — экспорт идёт на сервере: можно закрыть браузер, выгрузка не прервётся. При возврате страница подхватит статус и готовый архив.
- **Пуш в Telegram** — по завершении экспорта бот присылает ZIP прямо в чат (настраивается, см. `.env`).
- **Граф связей** — интерактивная сетевая карта: типизированные связи (ответы / упоминания / реакции), кластеры, фильтр по силе связи.
- **Радар (телеметрия)** — активность участников по времени, общая линия чата, сравнение двух периодов.
- **Досье (ИИ)** — глубокий профайлинг участников через Gemini (нужен свой API-ключ).
- **Бэкап PostgreSQL → Telegram** (`tg_backup/`) — дамп всех баз, нарезка и отправка ботом.

## Установка (Termux / Linux)

```bash
git clone https://github.com/kipingame-cell/tg-matrix-kit
cd tg-matrix-kit
npm install --ignore-scripts   # --ignore-scripts важен для Termux (bufferutil не собирается)
echo "SESSION_SECRET=$(head -c 24 /dev/urandom | base64)" > .env
npm start
```

Открыть в браузере: **http://127.0.0.1:3000/tg/**

## Установка (Docker)

```bash
docker build -t tg-matrix-kit .
docker run -d --name tgkit \
  -p 3000:3000 \
  -v $(pwd)/tg_sessions:/app/tg_sessions \
  -v $(pwd)/exports:/app/exports \
  -e SESSION_SECRET=$(head -c 24 /dev/urandom | base64) \
  tg-matrix-kit
```

Тома обязательны: `tg_sessions` — зашифрованные сессии (чтобы не входить заново после перезапуска контейнера), `exports` — архивы выгрузок.

## Вход в Telegram

1. Введи любой логин/пароль в окне «АВТОРИЗАЦИЯ» (это локальная защёлка интерфейса, значения любые, но не пустые).
2. Введи номер телефона → код придёт **в приложение Telegram** (служебный чат «Telegram», не SMS).
3. Если кода нет — кнопка «ВЫСЛАТЬ ПО SMS/ЗВОНКОМ» переключает канал доставки.
4. Если включена двухфакторка — введи пароль 2FA.

Сессия сохраняется (шифруется AES-256, ключ от `SESSION_SECRET` + sid): повторный вход не нужен, пока не нажат «ВЫХОД» или Telegram не отозвал авторизацию.

Клиент маскируется под официальный Telegram Android (Samsung Galaxy S23 Ultra, Android 13.0, клиент 9.6.5) с официальными публичными ключами API — это сильно повышает шанс доставки кода. Свои ключи с my.telegram.org можно задать через `TELEGRAM_API_ID` / `TELEGRAM_API_HASH` в `.env`.

## Как читать граф связей

- **Узел** = участник чата. Размер — число сообщений.
- **Три типа связей A → B**: **ответы** (серые сплошные), **упоминания** (оранжевые, штрих), **реакции** (розовые, пунктир). Толщина — частота. Легенда — в панели «КАК ЧИТАТЬ ГРАФ».
- **Цвет узлов** — два режима (кнопка ВЛИЯНИЕ/КЛАСТЕРЫ): индекс влияния (зелёный → красный) или кластеры — автоматические сообщества, кто общается внутри своего круга.
- **Слайдер «СИЛА СВЯЗИ»** — прячет слабые связи: убирай шум, оставляй только крепкие контакты.
- **Чекбоксы типов** — выключи реакции или упоминания, если мешают.
- **Клик по узлу** — досье: сообщений, исходящие/входящие связи, влияние, топ-5 контактов.
- **Поиск** — подсвечивает объект и его окружение, остальное гаснет.
- Кнопки: ВПИСАТЬ (масштаб), ПЕРЕМЕШАТЬ (пересчитать раскладку), ИМЕНА (скрыть подписи). Узлы таскаются, колёсико/щипок — зум.

## Как читать радар

- **ПО УЧАСТНИКАМ** — линия активности каждого выбранного участника + белая линия «ВЕСЬ ЧАТ» (общая активность).
- **СРАВНЕНИЕ ПЕРИОДОВ** — задаёшь два отрезка времени (A и B), радар растягивает оба на шкалу 0–100% и накладывает друг на друга. Под графиком — итог: сколько сообщений в каждом периоде и изменение в %. Удобно сравнивать «неделя против недели» или «месяц против месяца».

## Пуш-уведомления о выгрузке

Экспорт идёт на сервере в фоне — закрытие браузера его не прерывает. Чтобы получить ZIP сразу в Telegram:

1. Создай бота у @BotFather, получи токен.
2. Напиши боту любое сообщение, узнай свой chat_id (например через @userinfobot).
3. Добавь в `.env`:

```
TG_BOT_TOKEN=123456:ABC...
TG_CHAT_ID=123456789
```

После каждой выгрузки бот пришлёт ZIP (до ~45 МБ; большие архивы — только уведомление, файл забирай со страницы). Если Telegram недоступен напрямую — укажи прокси: `TG_PROXY=socks5://127.0.0.1:9050`.

## Переменные окружения (.env)

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `SESSION_SECRET` | соль шифрования сессий (обязательно задать!) | — |
| `PORT` | порт сервера | 3000 |
| `TELEGRAM_API_ID` / `TELEGRAM_API_HASH` | свои ключи API (не рекомендуется) | официальные |
| `FORCE_TOR=1` | ходить в Telegram только через Tor (127.0.0.1:9050) | выкл |
| `USE_TOR=0` | отключить Tor-фолбэк при сбое прямого соединения | вкл |
| `TG_BOT_TOKEN` | токен бота для пушей о выгрузке и `tg_backup/` | — |
| `TG_CHAT_ID` | куда слать пуши | — |
| `TG_PROXY` | socks5-прокси для Bot API (например `socks5://127.0.0.1:9050`) | — |

## Бэкап PostgreSQL → Telegram

```bash
cd tg_backup
TG_BOT_TOKEN=... TG_CHAT_ID=... ./backup.sh
```

Дампит все базы `pg_dump`, жмёт gzip, режет на части по 1900 МБ и шлёт ботом (маленькие — через Bot API, большие — через `send.py` на Pyrogram).

## Безопасность

- `.env`, `tg_sessions/`, `exports/`, `*.session` — в `.gitignore`, не коммить.
- Сессия Telegram = полный доступ к аккаунту. Хранить только локально, не пересылать.
- Не запрашивай код много раз подряд — Telegram включает молчаливый лимит (FLOOD_WAIT) на номер.

## Структура

```
server.js            — Express-сервер (порт 3000)
src/tg_auth.js       — авторизация Telegram (sendCode/signIn/2FA), фоновые задачи экспорта
src/telegram_core.js — ядро выгрузки (сообщения, архив, типизированный граф, радар, досье)
src/bot_notify.js    — пуш в Telegram по завершении экспорта (sendDocument с ZIP)
src/tg_export.js     — SSE-стрим участников, скачивание файлов
src/ai_engine.js     — профайлинг через Gemini
public/tg/           — терминал (интерфейс)
public/graph/        — сцена графа связей (D3: типы связей, кластеры, фильтры)
public/heatmap/      — радар активности (Chart.js: общая линия, сравнение периодов)
tg_backup/           — бэкап PostgreSQL → Telegram
Dockerfile           — контейнер (node:20-alpine, тома tg_sessions/exports)
```
