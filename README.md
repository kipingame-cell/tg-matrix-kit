# TG MATRIX KIT

Локальный терминал для выгрузки и анализа Telegram-чатов. Работает на твоём устройстве (ПК или Android через Termux), ничего не уходит на чужие серверы.

## Возможности

- **Выгрузка чатов** — сообщения в TXT / HTML / JSON, нарезка на части, превью медиа, ZIP-архив.
- **Фильтры** — по ключевым словам, участнику, датам, веткам (топикам) форумов, типу контента.
- **Граф связей** — интерактивная сетевая карта: кто с кем общается, кто хаб, кто на периферии.
- **Радар (телеметрия)** — активность участников по времени, графики по каждому.
- **Досье (ИИ)** — глубокий профайлинг участников через Gemini (нужен свой API-ключ).
- **Бэкап PostgreSQL → Telegram** (`tg_backup/`) — дамп всех баз, нарезка и отправка ботом.

## Установка (Termux / Linux)

```bash
git clone https://github.com/kipingame-cell/tg-matrix-kit
cd tg-matrix-kit
npm install --ignore-scripts   # --ignore-scripts важен для Termux (bufferutil не собирается)
echo "SESSION_SECRET=$(head -c 24 /dev/urandom | base64)" > .env
npm start
```

Открыть в браузере: **http://127.0.0.1:3000/tg/**

## Вход в Telegram

1. Введи любой логин/пароль в окне «АВТОРИЗАЦИЯ» (это локальная защёлка интерфейса, значения любые, но не пустые).
2. Введи номер телефона → код придёт **в приложение Telegram** (служебный чат «Telegram», не SMS).
3. Если кода нет — кнопка «ВЫСЛАТЬ ПО SMS/ЗВОНКОМ» переключает канал доставки.
4. Если включена двухфакторка — введи пароль 2FA.

Сессия сохраняется (шифруется AES-256, ключ от `SESSION_SECRET` + sid): повторный вход не нужен, пока не нажат «ВЫХОД» или Telegram не отозвал авторизацию.

Клиент маскируется под официальный Telegram Android (Samsung Galaxy S23 Ultra, Android 13.0, клиент 9.6.5) с официальными публичными ключами API — это сильно повышает шанс доставки кода. Свои ключи с my.telegram.org можно задать через `TELEGRAM_API_ID` / `TELEGRAM_API_HASH` в `.env`.

## Как читать граф связей

- **Узел** = участник чата. Размер — число сообщений. Цвет — индекс влияния (зелёный → жёлтый → красный).
- **Связь A → B** = A отвечал B (реплаи). Толщина — частота ответов.
- **Клик по узлу** — досье: сообщений, кому отвечал, кто отвечал ему, ближайший круг.
- **Поиск** — подсвечивает объект и его окружение, остальное гаснет.
- Кнопки: ВПИСАТЬ (масштаб), ПЕРЕМЕШАТЬ (пересчитать раскладку), ИМЕНА (скрыть подписи).
- Узлы можно таскать. Колёсико/щипок — зум.

## Переменные окружения (.env)

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `SESSION_SECRET` | соль шифрования сессий (обязательно задать!) | — |
| `PORT` | порт сервера | 3000 |
| `TELEGRAM_API_ID` / `TELEGRAM_API_HASH` | свои ключи API (не рекомендуется) | официальные |
| `FORCE_TOR=1` | ходить в Telegram только через Tor (127.0.0.1:9050) | выкл |
| `USE_TOR=0` | отключить Tor-фолбэк при сбое прямого соединения | вкл |
| `TG_BOT_TOKEN`, `TG_CHAT_ID`, `TG_PROXY` | для `tg_backup/` | — |

## Бэкап PostgreSQL → Telegram

```bash
cd tg_backup
TG_BOT_TOKEN=... TG_CHAT_ID=... ./backup.sh
```

Дампит все базы `pg_dump`, жмёт gzip, режет на части по 1900 МБ и шлёт ботом (маленькие — через Bot API, большие — через `send.py` на Pyrogram).

## Безопасность

- `.env`, `tg_sessions/`, `exports/`, `*.session` — в `.gitignore`, не коммить.
- Сессия Telegram = полный доступ к аккаунту. Хранить только локально, не пересылать.
- Не запрашивай код много раз подряд — Telegram включает молчаливый лимит (FLOOD_WAIT) на номер.

## Структура

```
server.js            — Express-сервер (порт 3000)
src/tg_auth.js       — авторизация Telegram (sendCode/signIn/2FA), фоновые задачи экспорта
src/telegram_core.js — ядро выгрузки (сообщения, архив, граф, радар, досье)
src/tg_export.js     — SSE-стрим участников, скачивание файлов
src/ai_engine.js     — профайлинг через Gemini
public/tg/           — терминал (интерфейс)
public/graph/        — сцена графа связей (D3)
public/heatmap/      — радар активности (Chart.js)
tg_backup/           — бэкап PostgreSQL → Telegram
```
